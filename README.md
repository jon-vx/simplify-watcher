# Internship watcher

Checks SimplifyJobs/Summer2027-Internships every 5 minutes and pushes new
2027 Software / AI-ML internships and co-ops in the US to your phone via ntfy.
Boston-area, NYC, remote and co-op roles arrive as high-priority alerts.

Filters are in the CONFIG block at the top of `watch.py`.
`state.json` is created on the first run and stores listings already seen.
